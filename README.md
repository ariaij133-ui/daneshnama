## درباره دانش‌نما

دانش‌نما یک دانشنامه فارسی است که به موضوعات علمی گوناگون می‌پردازد:

- 🌌 نجوم و کیهان‌شناسی
- ⚛️ فیزیک
- 🧬 زیست‌شناسی
- 🌍 زمین‌شناسی
- 🤖 فناوری
- 🚀 فضا
